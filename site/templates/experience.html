Kill XP & Underdog XP

A hero kill is worth {{ data.killXpFormula.base }} × (victim's level + {{ data.killXpFormula.levelOffset }}) XP. The level gap between the two teams then scales that up or down.

The gap uses exact levels, including progress toward the next one: gap = victim − killer. The whole number picks a row below (a gap under 1 counts as 0). The fraction adds on top:

delta = flat bonus + fraction × 0.1 × fraction multiplier

Whole-level gap Flat bonus Fraction multiplier
{{ row.levelGap }}{% if row.levelGap == 5 %}+{% endif %} {{ row.truncMod }} {{ row.moduloMod }}

Kill a team that is ahead and the modifier is 1 + delta. This is the underdog bonus. Kill a team that is behind and it is 1 − delta. The modifier always stays between {{ data.clamp.min }} and {{ data.clamp.max }}.

Example: a level 11.4 team kills a hero on a level 14.8 team.

  1. Level gap: 14.8 − 11.4 = 3.4, so the whole gap is 3 and the fraction is 0.4.
  2. Row 3 gives a flat bonus of 0.75 and a fraction multiplier of 4.
  3. Delta: 0.75 + 0.4 × 0.1 × 4 = 0.91.
  4. The victim's team is ahead, so the modifier is 1 + 0.91 = 1.91.
  5. Base kill XP uses the victim's whole level only: {{ data.killXpFormula.base }} × (14 + {{ data.killXpFormula.levelOffset }}) = 950.
  6. The kill is worth 950 × 1.91 = 1814.5 XP.
